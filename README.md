# 🏍️ Kallpa Motos — Motocross

Juego web 2D desarrollado con **Streamlit + HTML5 Canvas + JavaScript**.

## Características

- Motocross con desplazamiento lateral.
- Saltos y obstáculos.
- Rocas, barriles y rampas.
- Física sencilla de salto.
- Inclinación de la motocicleta con ← →.
- Puntuación y récord guardado en el navegador.
- Pantalla de inicio, pausa y game over.
- Compatible con PC y controles táctiles básicos en móvil.
- Diseño con branding **Kallpa Motos eléctricas y de motocross**.

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar desde GitHub

1. Crea un repositorio nuevo en GitHub, por ejemplo `kallpa-motos-game`.
2. Sube `app.py` y `requirements.txt`.
3. En Streamlit Community Cloud selecciona **Deploy an app**.
4. Selecciona tu repositorio.
5. En Main file coloca `app.py`.
6. Pulsa Deploy.

No necesita imágenes externas ni una base de datos.
